Chat-React-Context
Технологии: React, React-Context, TypeScript, Webpack, Bootstrap.

Возможности:
	1 подсчёт записей;
	2 подсчёт понравившихся записей;
	3 добавление новой записи;
	4 удаление записи;
	5 сделать избранной;
	6 отметить понравившейся;
	7 фильтрация по понравившимся;
	8 поиск по записям;

Минимальные стили с помощью библиотеку bootstrap,
без адаптива и отзывчивости.
